# 奶蛙园 · Naiwa Parkour

一只奶蛙在校园里跑酷，穿过拱门、湖畔、图书馆，躲开滚动的小球和地刺，收集 8 朵蓝花楹，最后抵达校门。

**整个游戏就一个文件：`index.html`** —— 零依赖、零外部请求、零构建，下载下来双击就能玩（图、音效、BGM、动画全部内嵌为 base64）。

## 怎么玩

| 操作 | 按键 |
| --- | --- |
| 跳跃 / 二段跳 | `空格` / `↑` / `W` / 点击画面 |
| 左右移动 | `←` `→` / `A` `D` |
| 加速跑 | `Shift` |
| 暂停 | `Esc` / `P` |

- **手机竖屏直接玩**：画布贴顶全宽，下半屏是加大号操作台（左下 ◀ ▶ 移动，右下 跑 / 跳），不用横屏；横屏和电脑端布局不变。

- 收集 **8 朵蓝花楹**，一路跑到拱门就算通关。
- 血量 3 颗心；碰到地刺、小球会扣 1 心（触发 `boom` 音效 + 巨石强森表情包轮替）。
- 靠近高台中段（x≈3620，进入约 260px 范围）就会触发 **TNT 炸弹事件**：TNT 立刻在头顶从天而降，落地后**闪白光倒计时约 2 秒**（越接近爆炸闪得越快、越急促）才爆炸，爆炸半径 200px，被炸到 **扣 2 颗心**，倒计时期间跑开就能躲掉。
- 通关后自动跳转 <https://www.jnu.edu.cn/>

## 技术说明

- 纯 Canvas 2D + 原生 JS，单文件约 6 MB（素材内嵌 base64）。
- 音效走 Web Audio API，BGM / mp3 用 `decodeAudioData`。
- 爆炸动画用 **PNG 雪碧图 + JS 逐帧取子矩形**播放（动画 GIF 在 Canvas 上帧不推进，不可靠）。
- 支持 `prefers-reduced-motion`（降低动效）。
